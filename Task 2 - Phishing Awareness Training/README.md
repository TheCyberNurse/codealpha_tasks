# CodeAlpha Phishing Awareness Training

## Project Overview

This project is a phishing awareness training presentation created as part of the CodeAlpha Cyber Security Internship.

The presentation focuses on helping users understand phishing attacks and recognize common warning signs.

## Topics Covered

* What phishing is
* How phishing attacks work
* How to identify phishing emails
* How to identify fake websites
* Social engineering tactics
* Types of phishing attacks
* Best practices to avoid falling victim
* Real-world phishing examples
* Interactive phishing awareness quiz
