# CodeAlpha Basic Network Sniffer

## Project Overview

This project is a basic network sniffer developed in Python using Scapy.

It captures network traffic packets and analyzes information such as:
- Source IP address
- Destination IP address
- Network protocol
- Source port
- Destination port
- Payload information

## Technologies Used

- Python
- Scapy
- Visual Studio Code
- Windows PowerShell
